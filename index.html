FrogOS

Tiny OS that lives in your browser

FrogOS is an operating system built in HTML, CSS, JavaScript and Python about Frogs :)

It comes with 2 apps: Frog Notes, for jotting things down that save automatically and Frog Browser, to search and visit other sites in the internet.
